# websitelab

The Phenome ring lab: a design laboratory page, split out of
[phenome-store](https://github.com/tiffanydesign/phenome-store) on 2026-09-21.

Live at https://tiffanydesign.github.io/websitelab/

Everything the page loads (sheets, scripts, fonts, images, films, frame
sequences) is in this repository under `/websitelab/`. Links to shop pages
(nav, search, cart, checkout) go to the phenome-store site on the same host.
